     - **Audit Regression Suites (`test_regressions_found_during_audit`)**: 5 dedicated regression test suites covering bugs found and hardened during audit:

       4. `bkt_stk` depth overflow handling when nesting depth exceeds 4096 brackets.
       5. Negative zero (`-0` and `-0.0`) sign preservation, non-integer rejection in `get_int64`, and `scan_number_fast` 8-digit integer boundaries.
     - **Multithreaded Concurrent Parsing**: `test_multithreaded_concurrent_parsing` verifies 8 threads × 40 iterations concurrently parsing and querying across `iterate()`, `parse()`, and `dom_parser` without data races or memory corruption.
     - **Full Stage 1 & Stage 2 Validation (`test_stage1_validation_errors`)**: Rejection of control characters (`error_code::unescaped_control`), unclosed strings (`error_code::unclosed_string`), syntax errors (`error_code::invalid_json`), depth limits (`error_code::depth_exceeded`), and trailing content (`error_code::trailing_content`).
     - **SIMD Boundary Sweeps & Escapes**: 64B and 128B chunk boundaries, quote-escape chains, prefix collisions, `test_mr_integer_range_edges` at 128-bit limits (`int64_t`, `uint64_t`, `__int128`, `unsigned __int128`), and lazy LINQ transducer checks (`test_lazy_linq_transducer_pipeline`).

## Rule 59 Sanitizer Verification (`CMakeLists.txt`)

FastestJSONInTheWest provides first-class support for Rule 59 sanitizers configured via CMake options:

1. **AddressSanitizer + LeakSanitizer + UndefinedBehaviorSanitizer (`-DENABLE_ASAN=ON`)**:
   - Compiler flags: `-fsanitize=address,undefined -fno-sanitize-recover=undefined -fno-omit-frame-pointer`
   - Link flags: `-fsanitize=address,undefined`
   - Verification: **3/3 `ctest` PASS (0 errors, 0 leaks, 0 undefined behaviors)** with `ASAN_OPTIONS=detect_leaks=1`.

2. **MemorySanitizer with Origin Tracking (`-DENABLE_MSAN=ON`)**:
   - Compiler flags: `-fsanitize=memory`, `-fsanitize-memory-track-origins`, `-fno-sanitize-memory-use-after-dtor`, `-fno-omit-frame-pointer`
   - Compatibility headers & shims: uses `cmake/msan_libcxx_compat.h` and `cmake/msan_libcxx_shim.cpp` to provide MSan interceptors and origin unpoisoning for prebuilt `libc++.so.1` standard library routines.
   - Verification: **3/3 `ctest` PASS (0 uninitialized memory reads, 0 warnings)**.

3. **ThreadSanitizer (`-DENABLE_TSAN=ON`)**:
   - Compiler flags: `-fsanitize=thread -fno-omit-frame-pointer`
   - Link flags: `-fsanitize=thread`
   - Verification: **3/3 `ctest` PASS (0 data races)** on all multi-threaded parsing and parallel LINQ operations.

## Testing Methodology

### Valgrind Configuration
```bash
# Memcheck Settings
--leak-check=full              # Full leak detection
--show-leak-kinds=all          # All leak types
--track-origins=yes            # Allocation tracking
--log-file=<filename>          # Detailed logging

# Helgrind Settings
--tool=helgrind                # Thread safety checker
--history-level=approx         # Balanced speed/accuracy
--suppressions=<file>          # Optional suppressions
```

### Test Execution
1. Compile with Clang 21 in Release mode (`-O3`)
2. Run with Valgrind Memcheck for memory leaks
3. Run with Valgrind Helgrind for thread safety
4. Analyze results and generate report
5. Verify all application leaks are zero

### Performance Impact
- Native execution: ~2 seconds per test
- Under Valgrind: ~2-3 seconds per test (tool overhead acceptable)
